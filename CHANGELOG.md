## [0.1.0] - 2026-08-21

### Added

- Local browser parsing for common STDF V4 streams.
- `.stdf`, `.std`, `.stdf.gz`, and `.std.gz` selection.
- Run overview with yield, fail count, hard-bin Pareto, site balance, and test-time summary.
- Test explorer with histogram, site box plot, sequence trend, CDF, limits, and Cpk.
- Parametric wafer map and in-session run comparison.
- Synthetic IMU demo dataset with generic identifiers.
- Cross-platform local scripts, Dockerfile, Docker Compose, and commercial documentation.

### Known limitations

- Partial STDF record coverage; see `docs/STDF_SUPPORT.md`.
- No persistent project database, authentication, license activation, or server-side reporting.
- Comparison screen contains demonstration insights that are not yet generated by a validated analytics engine.
